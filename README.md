# Pokémon Champions Singles Matchup Lab

Experimental 1v1 singles Pokémon Champions simulator using the real Pokémon Showdown Champions mod. This version is not a validated competitive ranking tool. The auto move-selection is heuristic. See `/api/health` after deployment for engine status.

Pokémon Showdown is licensed under MIT. Public deployment on Render (free tier) uses a pinned source revision.
